# Components

## Canvas UI Primitives and Elements

### AddElementMenu
- **File**: `src/components/canvas/AddElementMenu.tsx`
- **Description**: Floating/inline menu to insert new elements (Headings, Text, Buttons, Images, Cards, Containers, Dividers) into a section.

### ElementToolbar
- **File**: `src/components/canvas/ElementToolbar.tsx`
- **Description**: Floating formatting toolbar appearing above selected visual elements (text styling, colors, alignment, delete/duplicate).

### ElementInspector
- **File**: `src/components/editor/ElementInspector.tsx`
- **Description**: Inspector sidebar for modifying element styles, dimensions, typography, colors, padding, border radius, and flex layout.

### SectionEditor
- **File**: `src/components/editor/SectionEditor.tsx`
- **Description**: Editor panel to configure section-level background, padding, layout options, and content.

### DesignTokenPanel
- **File**: `src/components/editor/DesignTokenPanel.tsx`
- **Description**: Theme and design token editor (color picker, font selection, spacing scales, shadow presets).

### AIChatPanel
- **File**: `src/components/ai/AIChatPanel.tsx`
- **Description**: AI assistant sidebar for generating sections, modifying elements, or restructuring the landing page.
